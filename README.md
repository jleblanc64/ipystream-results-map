# ipystream-results-map

1. **Fill the password value in `app.py`**
2. **Open a terminal and Navigate to the project directory:**
   `cd ipystream-results-map`
3. **Install the required dependencies:**
   `pip install -r requirements.txt`
4. **Start the application:**
   `python app.py`
5. **Access the interface:**
   Open the URL printed in the console.

The whole app code is in file `python/notebook.py`.
You may modify it directly or copy/paste it in an AI chatbot, and ask for modifications.
Then restart the app to see the changes
